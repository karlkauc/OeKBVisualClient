# Aktivitätsjournal

Das Aktivitätsjournal protokolliert alle Upload- und Download-Aktivitäten Ihres Instituts auf der FDP. Öffnen Sie die Seite über **Activity Journal** im Menüabschnitt **MONITORING**.

![Aktivitätsjournal](screenshots/06-aktivitaetsjournal.png)

## Filteroptionen

Oberhalb der Tabelle stehen folgende Filter zur Verfügung:

| Filter | Beschreibung |
|--------|-------------|
| **Date From** | Startzeitpunkt (Standard: 30 Tage vor heute) |
| **Date To** | Endzeitpunkt (Standard: heute) |
| **Action** | Filterung nach Aktivitätstyp: `All`, `Upload` oder `Download` |
| **Type** | Filterung nach Datentyp |
| **Search** | Volltextsuche über alle Spalten |

### Filter anwenden

- **Apply Filter** — Wendet die gewählten Filter an und lädt die Daten neu
- **Clear Filter** — Setzt alle Filter auf Standardwerte zurück

## Tabelle

| Spalte | Beschreibung |
|--------|-------------|
| **Time** | Zeitstempel der Aktivität (Format: `yyyy-MM-dd HH:mm:ss`) |
| **Action** | Art der Aktivität: `Upload` (blau) oder `Download` (grün) |
| **Type** | Datentyp der Aktivität |
| **Data Supplier** | Kurzcode des beteiligten Datenlieferanten |
| **User** | Benutzername, der die Aktion ausgeführt hat |
| **Document ID** | Eindeutige Kennung des Dokuments |
| **Details** | Zusätzliche Informationen zur Aktivität |

## Aktionsschaltflächen

| Schaltfläche | Beschreibung |
|-------------|-------------|
| **Refresh** | Tabelle mit aktuellen Daten neu laden |
| **Export to Excel** | Alle angezeigten Einträge als Excel-Datei exportieren |

## Statusanzeige

Am unteren Rand wird die Anzahl der angezeigten Einträge sowie der Suchtreffer angezeigt.
