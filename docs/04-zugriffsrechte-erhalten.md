# Zugriffsrechte erhalten

Diese Seite zeigt alle Zugriffsrechte, die Ihrem Institut von anderen Datenlieferanten eingeräumt wurden. Öffnen Sie die Seite über **Rights Received** im Menüabschnitt **ACCESS RIGHTS**.

![Zugriffsrechte erhalten](screenshots/04-zugriffsrechte-erhalten.png)

## Tabellenansicht

Die empfangenen Zugriffsrechte werden als TreeTable dargestellt. Jede Zeile enthält:

| Spalte | Beschreibung |
|--------|-------------|
| **Rule ID** | Eindeutige Kennung der Zugriffsregel |
| **Profile** | Datenprofil (z. B. `all`, `PKG`, `Vendor`) |
| **Content Type** | Art der Daten: `FUND`, `DOC` oder `REG` |
| **Data Supplier (Short)** | Kurzcode des Datenlieferanten |
| **Data Supplier (Long Name)** | Vollständiger Name des Datenlieferanten |
| **LEI** | Legal Entity Identifier |
| **OENB ID** | OeNB-Identifikationsnummer |
| **ISIN SC** | ShareClass-ISIN |
| **ISIN Segm.** | Segment-ISIN |
| **Fund Name** | Name des Fonds |
| **From** | Gültigkeitsbeginn |
| **To** | Gültigkeitsende |
| **Frequency** | Aktualisierungsfrequenz (`daily` oder `monthly`) |

## Suche

Das Suchfeld oberhalb der Tabelle durchsucht alle Spalten. Geben Sie einen Suchbegriff ein — die Tabelle wird in Echtzeit gefiltert. Die Anzahl der Treffer wird neben dem Suchfeld angezeigt.

## Excel-Export

Klicken Sie auf **Export to Excel**, um die aktuell angezeigte Tabelle als Excel-Datei zu exportieren. Ein Datei-Dialog ermöglicht die Wahl des Speicherorts.
