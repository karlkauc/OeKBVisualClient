# Glossar

Fachbegriffe und Abkürzungen im OeKB Visual Client.

| Begriff | Erklärung |
|---------|-----------|
| **Access Delay** | Verzögerung in Tagen, bis Daten nach dem Upload für den Empfänger sichtbar werden |
| **Access Rule** | Zugriffsregel, die festlegt, welcher Datenempfänger auf welche Daten zugreifen darf |
| **AIFMD** | Alternative Investment Fund Managers Directive — EU-Richtlinie für Manager alternativer Investmentfonds |
| **Block Size** | Anzahl der IDs, die in einem einzelnen API-Aufruf abgefragt werden (max. 10) |
| **Content Type** | Art der Daten auf der FDP: `FUND` (Fondsdaten), `DOC` (Dokumente) oder `REG` (regulatorische Berichte) |
| **DDS** | Data Supplier — Kurzcode des datenliefernden Instituts auf der OeKB-Plattform |
| **EMT** | European MiFID Template — standardisiertes Datenformat gemäß MiFID II |
| **EMIR** | European Market Infrastructure Regulation — EU-Verordnung über OTC-Derivate |
| **FDP** | Fonds Daten Portal — die zentrale Datenplattform der OeKB für Fondsdaten |
| **File-System-Modus** | Offline-Betriebsmodus der Anwendung, bei dem lokale XML-Dateien statt der FDP-Server verwendet werden (für Tests) |
| **Frequency** | Aktualisierungsfrequenz einer Zugriffsregel: `daily` (täglich) oder `monthly` (monatlich) |
| **ISIN** | International Securities Identification Number — 12-stellige internationale Wertpapierkennnummer |
| **KID** | Key Information Document — Basisinformationsblatt für Anleger |
| **KIIDs** | Key Investor Information Documents — Wesentliche Anlegerinformationen gemäß UCITS-Richtlinie |
| **LEI** | Legal Entity Identifier — 20-stellige internationale Kennung für Rechtsträger |
| **NTLM** | NT LAN Manager — Authentifizierungsprotokoll von Microsoft, verwendet in Unternehmensnetzwerken. Format: `DOMAIN\username` |
| **OeKB** | Oesterreichische Kontrollbank — zentrale Infrastrukturanbieterin für den österreichischen Finanzmarkt |
| **OeNB-ID** | Identifikationsnummer der Oesterreichischen Nationalbank für Investmentfonds (2–8 Ziffern) |
| **OFI** | Offene Fonds Information — österreichischer Standard für die Meldung von Fondsdaten |
| **PRIIPS** | Packaged Retail and Insurance-based Investment Products — EU-Verordnung für verpackte Anlageprodukte |
| **PRIIPS-KID** | Basisinformationsblatt gemäß PRIIPS-Verordnung |
| **Profil** | Datenprofil, das den Umfang der abgerufenen Daten bestimmt (z. B. `all`, `PKG`, `Vendor`, `OeNB`) |
| **Segment-ISIN** | ISIN auf Segment-Ebene (Unterebene eines Fonds) |
| **ShareClass-ISIN** | ISIN auf Anteilsklassen-Ebene |
| **Solvency II** | EU-Richtlinie für das Versicherungsaufsichtsrecht — Tripartite Template dient der Berichterstattung |
| **TPT** | Tripartite Template — standardisiertes Berichtsformat gemäß Solvency II |
